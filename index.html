Твики и приложения

AppSync Unified 116.0

Установка неподписанных / fakesigned IPA — нужен для установки приложений из раздела ipa/. Поддерживается iOS 5.0 – 18.2, обе архитектуры.

By Karen/あけみ · official page · deb (arm) · deb (arm64)

ElleKit 1.2

Tweak-инъектор, предоставляет mobilesubstrate (нужен AppSync Unified начиная с версии 1.1). Только для rootless / современных джейлбрейков — на iOS 10.3.3 и 12.5.8 с Cydia Substrate ставить не нужно.

By ElleKit Team · ellekit.space · deb (arm) · deb (arm64)

GitHub Legacy 1.1

Лёгкий клиент GitHub для iOS 5+: просмотр репозиториев, чтение README и скачивание релизов. Есть хук для Safari-редиректов.

com.githublegacy.app · Applications · iOS 5.0+ · deb (arm)

Приложения (.ipa)

Отдельные .ipa — качаются прямо со страницы ipa/ или по ссылкам ниже. Для установки нужен AppSync Unified (см. выше).

  • LegacyAI 3.5 — iOS 6.0+, 1.9 МБ
  • Ловит 1.1 — iOS 6.0+, 4.5 МБ
  • Clash of Clans 1.70 — iOS 4.3+, 29.8 МБ

Индекс обновляется скриптом update-repo.sh. Если Cydia не видит изменения — сделайте Refresh или удалите кеш: rm -rf /var/lib/apt/lists/* и apt-get update.
